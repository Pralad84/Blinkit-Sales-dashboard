Blinkit Sales Dashboard 📊

An interactive Blinkit Sales Dashboard built using Power BI to analyze sales performance, outlet distribution, item categories, and customer ratings. The dashboard provides clear business insights through dynamic visualizations and filters for better decision-making.

Features ✨
Total Sales, Average Sales, Number of Items, and Average Rating KPIs
Sales analysis by Item Type and Fat Content
Outlet Establishment trend analysis by year
Outlet Size and Outlet Location comparison
Sales distribution across different Outlet Types
Interactive filter panel for:
Outlet Location Type
Outlet Size
Item Type
Clean and professional dashboard design with interactive charts and visuals
Tools & Technologies 🛠️
Power BI
Data Visualization
Business Intelligence
Data Analysis
Dashboard Insights 📈
Total Sales reached $1M+
Supermarket Type1 generated the highest sales
Tier 2 outlets contributed the most revenue
Fruits, Snacks, and Household items were top-performing categories
Average customer rating remained around 3.9
Purpose 🎯

The purpose of this project is to demonstrate practical skills in data visualization, dashboard creation, and business data analysis using Power BI by transforming raw sales data into meaningful insights.
